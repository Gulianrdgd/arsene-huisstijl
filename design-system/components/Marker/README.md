Een band in `mint-bright` achter één of twee woorden. De enige manier om nadruk te geven; vet is voor koppen.

- Klasse `ar-marker`. Bandhoogte ongeveer 36% van de regelhoogte, onderaan (56% tot 92%).
- Eén keer per blok, op één of twee woorden. Nooit op een hele zin.
- Op donker geen band: het woord krijgt de tekstkleur `mint-bright` (gaat vanzelf in de donkere modus).
- In print: een effen band (zie `@media print` in het brand book), geen gradient.
