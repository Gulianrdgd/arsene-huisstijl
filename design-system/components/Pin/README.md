Het mintgroene punt. Het teken dat we leven.

- Klasse `ar-pin`; de maat volgt de lettergrootte (0,25 em). In print minstens 6 px.
- Gebruik: in statusregels ("live · uptime 99.98%"), voor on-states, als scheidingsteken tussen mono-labels, voor de actieve navigatie-item.
- Glow (`ar-pin--glow`) alleen op een donkere grond.
- Uit of offline: `ar-pin--off` (`warm-400`, geen glow). *Voorstel.*
- Altijd `mint`. Geen andere kleur, ook niet voor een foutstatus: gebruik dan tekst in `signal`.
